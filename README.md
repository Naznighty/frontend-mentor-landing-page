# Frontend Mentor Landing Page

A landing page inspired by Frontend Mentor, built with vanilla HTML, CSS and JavaScript. It includes interactive UI components: dropdown menus, tabs and a modal.

## Features

- Navbar with animated dropdown menus (Explore, For Companies)
- Tabs component
- Modal dialog
- Hero section, testimonials and "As featured on" section
- Footer with newsletter subscription (confirm and success alerts)
- Dropdowns close when clicking outside

## Built With

- HTML5
- CSS3 (Flexbox)
- JavaScript (ES6, DOM manipulation)
- Font Awesome
- Google Fonts (Bungee Shade)

## Project Structure

```
├── index.html
├── style.css
└── script.js
```

## Getting Started

1. Clone the repository:
```
   git clone https://github.com/Naznighty/frontend-mentor-landing-page.git
```
2. Open `index.html` in your browser.

## What I Practiced

- Building reusable interactive components with JavaScript
- Toggling classes to control UI state
- Layout with Flexbox
- Handling document-level click events
